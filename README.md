# Click Lunch — закрытый MVP

Заказ создаётся в Telegram Mini App: серверное меню → стандартный комплекс или настройка → корзина → регистрация перед первым оформлением → серверный расчёт → сохранённый заказ. Бот предоставляет «Открыть меню», «Мои заказы» и «Помощь».

Click используется как ссылка оплаты. Нажатие «Я оплатил» отправляет заказ на проверку; оплату подтверждает только владелец. Кухня получает подтверждённые заказы. QR открывает карточку, а выдача выполняется отдельной кнопкой после готовности. Бонусы начисляются один раз при выдаче.

Клиент загружает каталог и цены из API, работающего в одном процессе с ботом. Защищённые запросы проверяют подпись и срок Telegram initData. Повтор оформления после таймаута возвращает тот же заказ. Старые кнопки перенаправляют в Mini App; sendData заказы не создаёт.
