# Antigravity Bot

Telegram-бот для заказа завтраков, напитков и комплексных обедов. Бот хранит
меню, корзины, заказы и бонусы в SQLite, формирует локальный QR-код выдачи и
предоставляет администратору управление заказами, меню, рассылкой и CSV-отчётом.

Для заказа формируется ссылка оплаты через Click. Бонусы за заказ начисляются
после того, как администратор отмечает его выданным.

## Требования

- Python 3.11 или новее;
- Telegram-токен от [@BotFather](https://t.me/BotFather);
- Telegram ID администратора;
- доступ бота к каналу, если используется команда `/post`.

## Установка на Windows

Если команда `python --version` не работает, установите Python с
[python.org](https://www.python.org/downloads/windows/) и включите опцию
`Add python.exe to PATH`. После установки откройте новый PowerShell.

Из каталога проекта выполните:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Настройка и запуск

Переменные задаются в том же окне PowerShell, из которого запускается бот:

```powershell
$env:BOT_TOKEN = "токен_от_BotFather"
$env:ADMIN_ID = "123456789"
$env:CHANNEL_ID = "@имя_канала"
$env:ORDER_CHANNEL_ID = "-1004345951081"
$env:MINIAPP_URL = "https://click-lunch-tashkent.click-ai-c-l-0087.chatgpt.site"
$env:TZ_OFFSET = "5"
$env:PORT = "8080"
$env:DB_NAME = "click_lunch_v6.db"
$env:CLICK_SERVICE_ID = "52528"
$env:CLICK_MERCHANT_ID = "20421"

.\.venv\Scripts\python.exe main.py
```

`BOT_TOKEN` обязателен. Остальные значения:

- `ADMIN_ID` — числовой Telegram ID администратора;
- `CHANNEL_ID` — username или числовой ID публичного канала с меню;
- `ORDER_CHANNEL_ID` — ID закрытого служебного канала для новых заказов;
- `MINIAPP_URL` — публичный HTTPS-адрес мини‑приложения; включает кнопку
  «Открыть меню» и команду `/app`;
- `TZ_OFFSET` — смещение от UTC, по умолчанию `5`;
- `PORT` — порт health-check, по умолчанию `8080`;
- `DB_NAME` — путь к SQLite-файлу, по умолчанию `click_lunch_v6.db`.
- `CLICK_SERVICE_ID` и `CLICK_MERCHANT_ID` — реквизиты ссылки оплаты Click;
  по умолчанию используются прежние значения проекта `52528` и `20421`.

Если Telegram ID неизвестен, первый раз запустите бота без `ADMIN_ID`, отправьте
ему `/myid`, затем остановите его `Ctrl+C`, задайте `ADMIN_ID` и запустите снова.

## Быстрая проверка

Для отдельной тестовой базы перед запуском можно задать:

```powershell
$env:DB_NAME = "test_bot.db"
```

Затем проверьте сценарий:

1. Отправьте боту `/start` и поделитесь своим номером кнопкой Telegram.
2. Добавьте обычное блюдо или напиток в корзину.
3. Соберите комплексный обед, выбрав горячее, гарнир, салат и напиток.
4. Откройте корзину, выберите дату/время и нажмите «Подтвердить заказ».
5. Убедитесь, что бот прислал кнопку «Оплатить через Click» и QR-код.
6. Откройте `/admin`, переведите заказ через статусы «Готовится» и «Готов».
7. Нажмите «Выдан» либо отсканируйте QR с аккаунта администратора.
8. Проверьте, что бонусы начислились только после выдачи.
9. Создайте второй заказ и проверьте списание бонусов.
10. В `/admin` проверьте статистику, кухонную сводку и CSV-экспорт.

Health-check доступен по адресу `http://localhost:8080/` и должен отвечать `OK`.

## Telegram Mini App

Мобильная витрина находится в каталоге `miniapp/`. В ней доступны меню на
рабочую неделю, выбор горячего, гарнира, салата и напитка, редактирование состава
в корзине, комментарий к заказу, время выдачи и списание доступных бонусов. При
подтверждении бот повторно проверяет блюда и цены по своей базе, создаёт заказ и
присылает QR‑код.

Публичный адрес мини‑приложения уже задан в коде. `MINIAPP_URL` можно использовать
для его переопределения без изменения программы. После обновления перезапустите
бота — зарегистрированные пользователи увидят постоянную кнопку
«🍽 Открыть меню»; открыть приложение также можно командой `/app`.

## Недельные посты и фотографии

В разделе «Меню на неделю» используются локальные постеры и фотографии горячих
блюд и салатов из каталога `assets/`. Администратор может открыть `/admin`, нажать
«Опубликовать меню» и выбрать нужный день недели. Команда `/post` публикует меню
текущего дня, а `/post mon`, `/post tue`, `/post wed`, `/post thu` и `/post fri`
позволяют выбрать день вручную.

Для публикации задайте `CHANNEL_ID` и добавьте бота в канал с правом отправлять
сообщения. Тексты постов также собраны в `content/week-2026-08-31-menu-pack.md`.

## Хранение данных

SQLite-файл создаётся автоматически. При обновлении существующей базы недостающие
столбцы добавляются без удаления пользователей и заказов. Незавершённое состояние
диалога хранится в памяти, но корзина и дата её выдачи сохраняются в SQLite.

Не добавляйте в Git Telegram-токен, SQLite-базу, резервные копии и экспортированные
отчёты с телефонами клиентов.
